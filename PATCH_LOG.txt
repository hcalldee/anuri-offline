COMMAND CLI
-----------
new <nama>
    Membuat character baru.

delete
    Menghapus character setelah konfirmasi nama.

status
    Menampilkan level, HP, stat, ATK, MATK, DEF, MDEF, crit, miss chance,
    EXP, Spina, dan status map.

stat <nama> <jumlah>
    Mengalokasikan stat point. Contoh: stat agi 3

map
    Menampilkan seluruh map prototype.

move <map-id>
    Berpindah ke map yang terhubung.

explore
    Melihat deskripsi map dan daftar encounter.

battle
    Memulai battle random.

quests
    Melihat status cache quest lokal.

scrape-quests
    Mengambil quest dari map prototype.

scrape-quests all
    Mengambil quest dari seluruh map legacy Wiki.

wiki <path>
    Mengambil ringkasan halaman dari Iruna Wiki baru.

clear
    Membersihkan layar dan menampilkan menu ulang.

help
    Menampilkan daftar command.

quit
    Keluar dari game.


FORMULA STAT PROTOTYPE
----------------------
STR: ATK +2 per point.
INT: MATK +2 dan MDEF +1 per point.
VIT: Max HP +4 dan DEF +1 per point.
AGI: Miss Chance +1% per point, maksimum 50%.
DEX: Crit Chance +0.2% per point.
CRT: Crit Chance +1% per point.

Base player:
    HP 40, ATK 8, MATK 5, DEF 2, MDEF 2, Crit 5%, Miss 0%.


SUMBER DATA WIKI
----------------
Map tree episode 1:
    https://irunawiki.com/treemap/episode%201

Wiki monster/item page:
    https://irunawiki.com/

Legacy quest map API:
    https://v1.irunawiki.com/api/mapsearch/all

Legacy quest API:
    https://v1.irunawiki.com/api/quest?map=<map-id>

Environment variable opsional:
    IRUNA_WIKI_BASE_URL
    IRUNA_WIKI_LEGACY_BASE_URL


STRUKTUR FILE PENTING
---------------------
src/cli.js
    Loop CLI, menu, command, battle screen, dan status.

src/game.js
    Battle engine, random encounter, stat formula, level up, dan modifier.

src/db.js
    Load/save world, player, quest cache, dan delete character.

src/wiki.js
    HTTP adapter untuk Wiki baru dan API legacy quest.

data/world.json
    Definisi map, koneksi map, dan monster lokal.

data/player.json
    Save character aktif. Dibuat saat command new dijalankan.

data/quests.json
    Cache hasil scrape quest.
